Number Guessing Game

A simple and interactive number guessing game built using Python. The computer generates a random number between 1 and 100, and the player tries to guess it using hints.

Features
Random number generation between 1 and 100
Hints when the guess is too high or too low
Tracks the number of attempts
Handles invalid user input
Simple and beginner-friendly gameplay
Technologies Used
Python 3
Random module
Project Structure
NumberGuessingGame/
├── main.py
└── README.md

Installation and Setup
Clone the repository:
git clone https://github.com/riya-meshram12/NumberGuessingGame.git

Navigate to the project directory:
cd NumberGuessingGame

Make sure Python 3 is installed:
python --version

Run the game:
python main.py


On Windows, you can also use:

py main.py
